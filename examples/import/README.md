# Примеры файлов импорта

| Файл | Ожидаемый результат |
|---|---|
| `01-ok.json` | SUCCESS: добавлено 5. Ордены создаются один раз («Ultramarines» и «ULTRAMARINES» — один орден), десантники в точке (10; 20.5) получают одни координаты |
| повторная загрузка `01-ok.json` тем же пользователем | SUCCESS: добавлено 0, пропущено 5 (свои полные дубли) |
| `01-ok.json` другим пользователем (не админом) | FAILED 409: «Орден «Ultramarines» уже существует и принадлежит командующему …», ничего не создано |
| `02-validation-errors.json` | FAILED 400: список ошибок по всем записям; запись 1 корректна, но тоже не создаётся |
| `03-duplicates.json` | SUCCESS: добавлено 2, пропущено 1 («Test» и «  test » — один десантник) |
| `04-chapter-count-mismatch.json` | FAILED 409: у ордена «Mismatch» разная численность; запись 1 тоже откатывается |
| `05-broken.json` | FAILED 400: файл не является корректным JSON (строка, позиция) |
